# Digital Weather Simulator


## Repository
https://github.com/Gen20042/digital-weather-simulator


## Description
  My project is an interactive digital weather simulator built in Python that lets users experience different weather conditions, including rain, snow, and sunshine, through colorful animations. This project connects to digital arts and media by combining programming, animation, and interactive visual design to create an engaging experience.


## Features
- Feature 1: Rain Animation
  - Create animated raindrops that fall from the top of the screen using Python loops and random positions.

- Feature 2: Snow Animation
  - Create snowflakes that slowly fall across the screen using shapes and movement.

- Feature 3: Sunny Weather Animation
  - Display a bright sun with animated rays and a colorful background.

- Feature 4: Interactive Weather Controls
  - Allow users to switch between rain, snow, and sunshine using keyboard controls.


## Challenges
- Learn how to create smooth animations for different weather conditions using Python.
- Research how to use keyboard inputs to let users switch between rain, snow, and sunshine.
- Improve my understanding of particle movement, timing, and visual effects to make the weather animations look realistic.

## Outcomes
Ideal Outcome:
- My ideal outcome is to create a fully interactive weather simulator with smooth animations for rain, snow, and sunshine. Users will be able to switch between weather conditions using keyboard controls and experience colorful backgrounds and visual effects.

Minimal Viable Outcome:
- My minimum goal is to create a working Python program that displays at least two different weather animations, such as rain and snow. Even if the advanced visual effects are not completed, the program should run smoothly and allow users to switch between the two weather conditions.
